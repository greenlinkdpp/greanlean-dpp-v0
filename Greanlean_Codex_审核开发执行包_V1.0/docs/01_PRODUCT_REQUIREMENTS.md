# Greanlean电池护照平台产品需求基线 V1.0

## 1. 文档控制

- 文件属性：内部产品 / 研发 / 测试文档
- 编制日期：2026-08-03
- 适用范围：LMT电池、额定能量大于2 kWh的工业/储能电池
- 状态：工作基线；需随欧盟实施文件与语义目录更新
- 源文件：`reference/Greanlean_电池护照平台需求调整与开发实施文档_V1.0.docx`

本Markdown用于Codex执行，源文件仍是产品需求基线。本文不把实施建议自动提升为法定义务。

## 2. 执行摘要

- P0：在不依赖最终电池语义目录的前提下，完成企业入驻、适用性评估、单体级身份、URL型UPI、资料采集、证据审核、版本发布和可追溯输出。
- P1：完成多角色审批、字段级权限、BMS数据导入、Registry组织验证辅助、沙箱/预检和批量产品创建。
- P2：完成供应商协同、ERP/MES/BMS接口、批量注册适配、商业套餐及规模化运维。
- 平台边界：平台帮助企业组织、校验、发布和维护数据，但不自动产生法规认证、碳足迹核查或第三方验证结论。

核心结论：下一阶段不横向扩行业，优先把“户储 + LMT电池单型号试点”做成完整成交和交付闭环。

## 3. 客户与产品范围

| 优先级 | 客户群 | 典型产品 | 产品策略 |
|---|---|---|---|
| 主攻 | 户用储能电池企业 | 5-30 kWh壁挂式、机架式、高压/低压户储，已出口或计划出口欧盟 | 技术资料相对完整、产品通常大于2 kWh、便于形成BMS/系统接口增购 |
| 副线 | LMT电池包企业 | 电动自行车、滑板车、轻便摩托车及换电电池 | 范围清晰，适合快速单型号试点 |
| 扩展 | 中小型工业设备电池 | 叉车、AGV/AMR、高空作业平台、环卫及专用设备 | 形成2-3个户储/LMT真实案例后扩展 |
| 暂缓 | 大型动力电池及整车集团 | 集团型、多工厂、长采购链项目 | 当前销售周期和准入成本过高 |

## 4. 责任边界

- 平台负责：数据模板、字段条件、数据校验、证据关联、权限控制、版本发布、QR/UPI解析、机器可读输出、审计留痕和系统接口。
- 企业负责：原始数据真实性、合法来源、责任人确认、证据文件、持续更新及经济运营者责任。
- 第三方负责：碳足迹核查、检测认证、材料声明核验、LCA、尽职调查审验等专业结论。
- Registry负责：组织验证与DPP登记记录。平台不得在未获得官方URI时展示“官方注册成功”。

## 5. 当前能力与P0整改

当前已有能力包括：统一产品页面、二维码、PDF/JSON同源表达；身份、材料、碳、性能、安全、运行、供应链、证据和生命周期分区；多种数据状态；公众/专业/监管标签；版本、证据有效期和事件表达。

| 优先级 | 对象 | 问题 | 调整要求 | 验收标准 |
|---|---|---|---|---|
| P0 | 首页与销售入口 | 多行业展示过重 | 首屏聚焦电池护照；增加适用性评估、单型号试点、资料清单入口 | 3次点击内可提交一个型号的评估申请 |
| P0 | 护照粒度 | 型号级与单体序列号表达冲突 | Model为继承模板，BatteryItem为最终护照主体 | 每个已发布护照绑定唯一item_id和序列号 |
| P0 | 唯一标识 | DPP ID/GTIN/SGTIN未明确URL型UPI | 建立HTTPS可解析UPI；其他编码作为来源/业务标识 | 扫码稳定解析，不降级HTTP |
| P0 | Registry状态 | 准备与成功未严格区分 | 准备、预检、测试、生产提交、成功、失败状态；成功保存官方URI | 无URI不得显示成功 |
| P0 | 字段版本 | 法规、参考模型和平台字段易混用 | 字段具备source、version、legal basis、effective date、condition | 任一字段可追溯来源和版本 |
| P0 | 数据一致性 | 存在功率/粒度等逻辑冲突风险 | 单位、范围、跨字段、公式和新鲜度校验 | 发布前阻断关键冲突并定位 |
| P0 | 客户实施流程 | 缺少评估到发布工作台 | 项目、任务、责任人、缺口、审核和验收 | 项目可查看完整率、阻塞和交付物 |
| P1 | 字段级权限 | 目前主要是标签 | 权限配置化，服务器端执行 | API/导出同时受控 |
| P1 | BMS数据治理 | 快照来源和时序不规范 | CSV/API、时间、来源、质量、单位、异常、快照策略 | 历史值只追加，修正保留版本 |
| P2 | 商业化管理 | 缺套餐/工时/续费 | 合同项目、套餐、额度、服务期、增购和续费 | 可统计收入、工时和续费 |

## 6. 端到端流程

| 阶段 | 输入 | 责任角色 | 平台输出 | 状态门 |
|---|---|---|---|---|
| 01 线索与初评 | 企业、产品类别、欧盟市场、现有资料 | 销售/顾问 | 适用性初判、项目机会 | 待评估 |
| 02 项目立项 | 试点范围、型号、责任人 | 项目经理 | 客户空间、任务、里程碑 | 已立项 |
| 03 适用性确认 | 用途、额定能量、投放主体、销售模式 | 法规/实施 | 类别和责任角色初步确认 | 适用/不适用/待确认 |
| 04 粒度与标识 | 型号、批次、序列号、编码规则 | 产品/IT | Model-Batch-Item和UPI方案 | 身份方案已确认 |
| 05 数据采集 | BOM、材料、证书、碳、性能、BMS | 各部门 | 模板导入、缺口和责任人 | 采集中 |
| 06 证据与审核 | 声明、报告、记录、第三方文件 | 质量/法规 | 数据证据关联、状态和有效期 | 待审核/退回/通过 |
| 07 护照生成 | 已审核数据、权限、语言 | 平台/项目经理 | 页面、QR、PDF、JSON和快照 | 待发布 |
| 08 客户验收 | 展示、扫码、数据、权限、文件 | 客户/项目组 | 问题闭环和验收 | 已验收 |
| 09 Registry准备 | 组织资料、UPI、语义映射 | 经济运营者/平台 | 验证辅助、预检、提交记录 | 准备/提交/失败/成功 |
| 10 持续运维 | 证书、BMS、维修、再利用、回收事件 | 客户成功/企业 | 更新、续费、版本和生命周期 | 在用/暂停/归档 |

## 7. 功能模块M01-M18

| 模块 | 优先级 | 功能要求 | 关键规则 | 验收要点 |
|---|---|---|---|---|
| M01 企业/租户与经济运营者档案 | P0 | 多租户隔离；企业法定信息、国家、标识、联系人、EU角色、验证状态 | 组织信息与验证材料可比对；禁止跨租户 | 独立维护、完整率、Registry准备清单 |
| M02 适用性评估与项目管理 | P0 | 类别、能量、用途、投放角色、目标日期；任务和责任人 | 只能给初步判断 | 适用性报告、缺口、实施计划 |
| M03 产品主数据与层级 | P0 | ProductModel、Batch、BatteryItem三级；继承与覆盖 | 默认Item为发布主体 | 单型号批量创建不超过100个Item并导出 |
| M04 标识、UPI与二维码 | P0 | GTIN、SGTIN、序列号、UPI URL、二维码版本和解析 | HTTPS、唯一、可解析；旧链接可追溯 | 重复阻断，扫描可用 |
| M05 法规字段与Schema引擎 | P0 | 分组、类型、单位、条件、证据、权限、来源、版本、生效日期 | 法规/官方语义/参考/自愿字段分层 | 按类别加载模板并形成差距报告 |
| M06 BOM、组件、材料与物质 | P0 | 组件、质量、占比、化学体系、来源、关键原材料、关注物质 | 未知边界明确；合计阈值可配 | Excel导入、供应商、证据和版本差异 |
| M07 可持续性、碳足迹与再生成分 | P0/P1 | 数值、功能单位、边界、方法、数据期、核查、等级；再生成分 | 未核查不得标第三方验证 | 展示方法、边界和验证状态 |
| M08 性能、耐久与安全 | P0 | 容量、能量、电压、功率、效率、寿命、温度、内阻、安全 | 单位统一；声明值与测试值分开 | 异常阻断，可关联报告 |
| M09 BMS运行与健康 | P1 | SOC、SOH、容量、循环、温度、内阻、功率、吞吐量、时间、来源 | 快照/事件，不做秒级监控；只追加 | CSV/API、新鲜度、质量、异常 |
| M10 供应链与尽调 | P1 | 供应商、设施、地点、采购/制造/运输事件、声明、报告 | 敏感信息受控，未核验不标已验证 | 时间线可追溯 |
| M11 维修拆卸再利用报废 | P1 | 步骤、工具、防护、安全、备件、维修商、再利用/回收 | 生命周期只追加；新旧护照关联 | 状态变更和关联链 |
| M12 证据中心 | P0 | 类型、编号、签发方、日期、适用范围、哈希、版本、状态 | 历史不删除；敏感下载鉴权；到期提醒 | 关键数据可追溯证据或责任声明 |
| M13 访问权限和数据投影 | P1 | 公众、合法利益方、监管、内部；字段级策略 | 服务端鉴权，导出同权 | 未授权受控错误 |
| M14 审核、发布与版本 | P0 | 提交、退回、批准、发布、撤回；差异；快照 | 发布版本不可原地修改 | 版本、审批人、时间和差异可见 |
| M15 页面、PDF、JSON与多语言 | P0/P1 | 中英文页面、PDF、通用JSON和后续官方Schema | 同源；翻译状态；输出权限过滤 | 同版本一致性测试 |
| M16 Registry适配器 | P1 | 组织准备、标识、文件、提交、correlation ID、结果和URI | 无官方语义时禁用生产成功；URI为成功依据 | 测试配置、预检、错误报告 |
| M17 接口与批量导入 | P1/P2 | Excel/CSV、REST、Webhook、BMS/EMS/ERP/MES/PLM | 鉴权、幂等、重试、来源、错误隔离 | 行/字段级错误，API版本化 |
| M18 运维、套餐与客户成功 | P2 | 套餐、额度、服务期、工时、续费、增购、SLA | 商务和法规数据分域 | 收入、续费、活跃护照和工时 |

## 9. 数据状态

| 状态 | 定义 | 系统要求 |
|---|---|---|
| 待补充 | 适用但无可用数据 | 不得作为完整字段通过 |
| 企业声明 | 企业确认、尚无外部证据 | 记录声明人和时间 |
| 文件支持 | 报告/记录/声明文件支持 | 文件有效且范围匹配 |
| 第三方验证 | 独立机构核查 | 记录机构、范围、日期和证据 |
| 不适用 | 条件判断无需提供 | 填写理由和判断人 |
| 待确认 | 法规/责任/边界未确认 | 发布门禁可配置 |

## 10. 发布门禁和自动校验

发布门禁：身份、法规适用字段、证据、一致性、权限、版本和Registry状态。

| 编号 | 校验 | 处理 |
|---|---|---|
| ID-001 | UPI唯一且以https://开头 | 阻断 |
| ID-002 | 单体序列号在同一企业内唯一 | 阻断 |
| BAT-001 | 额定能量约等于标称电压×额定容量/1000，误差可配 | 警告/阻断可配 |
| BAT-002 | 剩余功率无解释不得超过产品允许最大功率 | 阻断或要求说明 |
| MAT-001 | 已填材料质量占比合计不超过100% | 阻断 |
| EVD-001 | 证据到期或型号不匹配 | 关键字段阻断 |
| TIM-001 | 测量、制造、投用、维修日期顺序合理 | 警告 |
| REG-001 | Registry成功必须有URI和官方返回 | 阻断 |
| PUB-001 | 页面/PDF/JSON版本号和更新时间一致 | 阻断 |

## 11. 非功能要求

- 月可用性目标不低于99.5%；公共解析与后台管理解耦。
- 公共页面P95首屏不高于3秒；常规JSON不高于2秒；批量导入异步。
- P0每租户支持10万BatteryItem；时序数据冷热分层。
- 数据库每日全量+持续增量；证据多副本；恢复演练。
- 中英文；单位、日期、时区和翻译状态可配置。
- 移动端扫码；图表有文本值；基础可访问性。
- 字段配置化、API版本化、配置与代码分离、关键任务可重放。
- 监控UPI解析、页面错误、导入失败、证据到期、Registry错误和数据新鲜度。

## 13. 首版Definition of Done

1. 可由真实客户资料创建企业、项目、型号、可选批次和单体护照。
2. 单体具有唯一HTTPS UPI，扫码可解析，页面/PDF/JSON同源。
3. 关键字段有条件、单位、来源、证据、状态和责任人；缺口可导出。
4. 审核发布形成不可变版本，更正和生命周期事件留痕。
5. 公众与受限数据由服务端权限控制。
6. Registry模块支持资料准备、UPI预检和提交记录；不可用时不宣称已注册。
7. 完成至少1个户储和1个LMT样例的端到端回归。
