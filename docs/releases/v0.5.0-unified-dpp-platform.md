# v0.5.0 Unified DPP Platform

Release date: 2026-07-25

## Summary

This release consolidates Greanlean into one cross-industry DPP platform. The
homepage, four primary product passports, publication data, identity controls,
and battery operating data now follow one architecture and release process.

## User-visible changes

- The homepage presents Greanlean as a multi-industry DPP platform and retains
  a dedicated Battery Passport section.
- LMT battery, stationary industrial battery, textile, and consumer-electronics
  cases use the same page shell, navigation, content hierarchy, and responsive
  behavior.
- Public visitors see the consumer-safe publication projection.
- Approved users sign in to receive a server-authorized professional or
  regulatory projection.
- Battery users with access can see operating snapshots, history, source,
  freshness, quality state, and lifecycle events.
- Chinese and English pages use the same information structure.

## Data and security

- Public pages and exports read versioned database publication snapshots.
- Audience query parameters cannot increase privileges.
- Organisation roles, product grants, access requests, and audit records are
  enforced on the server and in database policies.
- Public endpoints do not return battery item telemetry.
- Device integration credentials are stored as hashes.
- Operating metrics, lifecycle events, and ingestion logs are append-only.

## Limitations

- No production BMS, EMS, gateway, or maintenance vendor is connected.
- Seeded battery operating records are initial, unverified records and must not
  be represented as live device telemetry.
- EU DPP Registry production submission remains disabled until the official
  battery semantic catalogue and production credentials are available.
