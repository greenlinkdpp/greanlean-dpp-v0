# v0.4.0 Battery Passport Demo Expansion

Release date: 2026-07-24

## Summary

This release makes battery passports the first public capability shown by
Greanlean and adds a complete synthetic stationary industrial battery example.
The implementation reuses the existing normalized battery model and does not
add a database migration.

## User-visible changes

- The homepage now explains LMT, EV and industrial battery passport data.
- The four featured demos are LMT battery, industrial battery, textile and
  consumer electronics.
- GreenVault ESS-14.3 has Chinese and English consumer, professional and audit
  presentations.
- The public passport includes an HTTPS UPI, QR code, product image, model,
  batch, item, technical specifications, materials, carbon, circularity,
  durability and lifecycle information.
- Professional previews show synthetic operating history, safe dismantling
  guidance and document placeholders.
- JSON export returns the structured industrial battery payload. Public
  consumer pages do not display the JSON download action.

## Data installation

Run `supabase/seeds/industrial_battery_demo.sql` in Supabase SQL Editor after
the existing product-category profiles and migrations `0009` and `0010`.

The script is idempotent and ends with a verification query. A successful row
contains:

```text
DPP-GV-ESS-14K3-000001
green-vault-ess-14-3-demo-000001
GV-ESS-14K3-2026
BATCH-202606-DEMO
GV14K3-DEMO-000001
```

Use `supabase/seeds/industrial_battery_demo.rollback.sql` to remove only this
demo. Existing LMT and legacy cases are untouched.

## Limitations

- All GreenVault data is synthetic.
- There is no live BMS integration.
- There is no official certification or third-party verification.
- There is no formal EU DPP Registry submission.
- Placeholder documents intentionally contain no fabricated laboratory,
  certificate or signature.
