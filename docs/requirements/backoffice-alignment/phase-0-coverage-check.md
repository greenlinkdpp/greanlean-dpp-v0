## 3. 四个正式案例

### 3.1 LMT 电池

`DPP-LMT-BAT-48V15AH`

覆盖：

- DPP、GTIN/SGTIN、SKU、批次和序列号；
- LMT 电池规范字段；
- 型号、批次和单体关系；
- BatteryPass 静态字段；
- 运行指标和生命周期事件；
- 公众与授权动态投影；
- PDF、JSON 和 Registry TEST 映射。

需在阶段 1 核验：

- 当前首页字段是否全部来自权威数据；
- 动态指标的时间、来源和质量状态；
- 合法利益用户是否只能读取被授权单体。

### 3.2 工业储能电池

`DPP-GV-ESS-14K3-000001`

覆盖：

- 工业电池子分类；
- 与 LMT 相同的九模块版式；
- 工业性能、安全和运行指标；
- 单体动态数据；
- 生命周期事件。

需在阶段 1 核验：

- 不再使用独立演示页面；
- 字段适用性根据工业电池模板计算；
- 动态指标单位与 LMT 使用同一目录。

### 3.3 纺织品

`DPP-SFJK-31-1-REC`

覆盖：

- 纤维组成、再生含量和来源；
- 化学品与受限物质；
- 产品性能和护理；
- 合规证据与报告；
- 循环和生命周期结束。

需在阶段 1 核验：

- 下载文件必须是数据库中的真实文件版本；
- 不再自动生成冒充检测报告的 PDF；
- 中文页面不显示英文描述；
- 证据访问权限与字段一致。

### 3.4 消费电子

`DPP-CE-EARBUDS-001`

覆盖：

- 产品数字身份；
- 电子组件、关键材料和环境数据；
- 耐久、维修和回收；
- 内置便携式电池的适用性引用。

需在阶段 1 核验：

- 消费电子产品与电池护照不重复维护相同事实；
- 只有达到独立电池护照要求时才关联电池 DPP；
- 公众首页不突出内部数据版本或重复证书数量。

## 5. 已发现且必须在阶段 1 消除的断点

1. 当前普通产品保存生成的版本不包含全部关联数据；
2. 当前统一发布快照主要保存 `publicDpp`，不能恢复专业和监管投影；
3. 多个关联表由浏览器直接写入；
4. Registry、审计和区块链记录仍可被通用表单维护；
5. 页面存在硬编码业务值和回退文案；
6. 结构化对象可能直接显示为 JSON 字符串；
7. 通用五行业生命周期事件缺少统一数据层；
8. 文件不可变版本和字段证据关系需要补强；
9. 家具和建材缺少正式案例数据；
10. 当前发布版本与草稿之间缺少稳定的字段级差异。

## 6. 阶段 0 通过条件

- 九个模块均有目标权威来源；
- 五行业均有分类和行业专属承载方式；
- 四个正式案例均有回填与双读计划；
- 完整快照不是公开字段子集；
- 公众、专业、监管和内部投影来自同一版本；
- 电池动态数据边界明确；
- 数据库变更可分批实施和回滚；
- 没有要求阶段 1 立即删除历史表或历史数据。

上述条件全部满足，可以在用户确认后进入阶段 1。
