# 四类产品双轨读取核验报告

核验日期：2026-07-25

## 结论

M3 标准聚合候选数据已通过四个代表产品的只读双轨核验。旧公开读取路径与新九模块聚合路径的 8 项核心身份事实全部一致，公开投影未发现受限字段泄漏。

本报告只确认“标准聚合数据具备进入发布链路联调的条件”，不代表公开 DPP 页面已经切换到新读取路径。

## 核验范围

对每个产品核对以下核心事实：

- DPP ID
- 产品名称
- 品牌 / 制造商
- 型号 / SKU
- 唯一产品标识
- GTIN
- 批次
- 序列号

同时检查：

- 九个标准模块均可生成
- PUBLIC 投影不包含受限字段
- 聚合结果可生成稳定来源指纹和快照哈希

## 已修复问题

首次核验时，LMT 电池的序列号存在一项差异：

- 旧公开路径：使用 `battery.battery_serial_number`
- 新标准聚合路径：使用 `product_digital_identity.serial_id`

现已统一规则：电池法规静态字段提供序列号时，产品身份模块使用该值，并保留 `battery_field_value` 来源信息；`battery_item.serial_identifier` 继续作为单体运行对象信息保存在追溯模块，不覆盖产品护照身份。
