# Decisions Required

以下事项不阻断 P0。实现采用最保守、可配置、可回滚的默认值；在获得正式文件或业务确认前，不写成法律认证结论。

状态更新时间：2026-08-03。P0 代码完成后，下列外部/业务决定仍未由仓库事实解决。

## 已作出的工程决策

- 新能力优先复用 `dpp_organisation`、`battery_*`、`dpp_publication`，不建立第二套平行护照系统。
- 现有 product 级发布保留为 legacy；新增 subject 字段支持 BatteryItem，不重写历史快照。
- 所有新项目和新电池 item 必须有组织归属；历史未归属数据不做推断性回填。
- 页面、PDF、JSON 以同一不可变发布快照为权威源；动态运行数据作为授权后的附加实时视图，不写入静态发布快照。
- 正式 Registry 和区块链都不是 P0 发布必要条件。
