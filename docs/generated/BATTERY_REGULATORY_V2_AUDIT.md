# Battery Regulatory v2.0 Audit

审核日期：2026-09-06  
来源：`Digital Batteries Passport - data point by category.pdf`，文档标注 v2.0，2026-08-15。  
性质：实施参考资料；不代表欧盟委员会正式立场，也不替代法规原文、授权法案、实施法案或专业法律意见。

## 1. 来源核对

- 共 71 个连续编号数据点，平台未删减原始编号。
- 每个数据点分别保留 EV、LMT、Industrial 三列适用状态。
- EV：47 必填、8 条件、1 可选、8 未来、2 重复、5 不适用。
- LMT：50 必填、8 条件、1 可选、8 未来、2 重复、2 不适用。
- Industrial：32 必填、26 条件、1 可选、8 未来、2 重复、2 不适用。
- 法规来源与英文原始注记逐点保留；界面提供中文名称和中文注记。

## 2. 现状差异与处理

旧实现以 BatteryPass-Ready Longlist v1.3 的 100 字段和五份校验 Schema 为主要录入目录，无法直接表达 71 点指南中的三类独立适用性、future/duplicate 状态及产品级条件退出。新实现不删除旧适配器，而是增加法规工作目录：

- A 精确映射 49 项：复用现有规范字段。
- B 部分映射 12 项：保留旧字段别名，待专家确认语义边界。
- C 扩展 1 项：新增规范字段，不伪造旧值。
- D 删除/调整 2 项：作为重复项保留配置，普通录入和展示隐藏。
- E 粒度调整 7 项：保留值，但由型号/批次/单体/生命周期解析规则决定最终值。

完整逐项清单见 `BATTERY_REGULATORY_V2_MAPPING.csv`。

## 3. 数据与界面设计

- 十章：身份、制造、材料、可持续性、性能、安全、维修、健康与动态、生命周期、来源与证据。
- 字段由 JSON 目录驱动，React 页面没有硬编码 71 行。
- 每个值保存数据状态、来源类型/引用、证据状态与数量、核验状态、专家复核状态和更新时间。
- future、duplicate、not_applicable 不显示在普通表单，也不计入缺失字段。
- conditional 默认进入完整度；具备理由并明确标记 not_applicable 后退出分母。
- DP67 电池生命周期状态与 DPP publication 状态完全分离。
- 动态运行数据继续使用受限、追加式运行指标与生命周期事件，不覆盖静态声明。

## 4. GreenVault ESS-14.3

该产品只按工业固定式 2 kWh 以上电池处理，不引用 EV 或 LMT 列。目录层面适用范围为 32 个必填、26 个条件、1 个可选；最终条件项仍需依据具体设计和证据逐项确认。

迁移不删除既有数据，也不以行业常规值填补未知事实。已有值如没有字段证据链接，保留为 `declared/unverified`，专家复核为 `pending`。产品 URL、DPP ID 和历史发布版本保持不变。

## 5. 输出边界

- 页面、通用 JSON 和 PDF 均调用相同的公开法规投影。
- 专业和监管字段仅由服务器权限投影返回。
- BatteryPass JSON 是面向外部校验器的独立适配器，不等同于 71 点法规工作目录。
- 真实 BMS/EMS、欧盟 Registry 和外部区块链生产连接不在本次交付中，不显示为已接通或已验证。

## 6. 待专家确认

- 64 个数据点默认处于 `pending` 专家复核状态；7 个明确 future/duplicate 项为 `not_required`。
- 条件项是否适用于 GreenVault 的具体工程判断。
- B/C/E 映射项的字段语义与粒度。
- 后续授权/实施法案发布后，对 8 个 future 项启用条件与数据格式进行版本升级。
